# 📦 TravelDrop - Smart Parcel Delivery App

TravelDrop is a **Flutter + Firebase-based mobile application** that enables users to send parcels through travelers heading in the same direction. The platform provides a secure, cost-effective, and eco-friendly delivery solution with real-time updates and verification mechanisms.

---

## 🚀 Key Features

### 👤 User Features

* 📦 Post parcel delivery requests
* 🧭 Find travelers going in the same direction
* 🔐 Secure login & authentication (Firebase)
* 🪪 KYC verification system for user trust
* 🔔 Real-time notifications for updates
* 🔑 OTP-based parcel delivery confirmation
* 📜 View parcel history and transaction details
* 💳 Save and manage payment details

---

### 🧳 Traveler Features

* 🚗 Accept parcel delivery requests
* 📍 Deliver parcels along travel route
* 💰 Earn money for deliveries

---

### 🧑‍💼 Admin Features

* 👥 Manage all users and verification status
* ✅ Approve / Reject KYC applications
* 💳 Monitor all transactions and payments
* 📊 View system-wide activity dashboard
* 🚨 Handle user reports and complaints

## ⚙️ Installation & Setup

### 1. Clone the repository

```id="td2"
git clone https://github.com/YOUR-USERNAME/TravelDrop.git
cd TravelDrop
```

---

### 2. Install dependencies

```id="td3"
flutter pub get
```

---

### 3. Firebase Setup

* Create a project in Firebase
* Enable:

  * Authentication
  * Firestore Database
  * Storage
* Download `google-services.json` (Android)
* Place it inside:

```id="td4"
android/app/
```

---

### 4. Run the app

```id="td5"
flutter run
```
